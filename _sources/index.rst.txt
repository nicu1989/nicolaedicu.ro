What I do
---------

**Build systems & developer tooling**
  Design and maintain build workflows using Bazel, Starlark, CMake and SCons.
  Develop custom build rules, integrate C++ and Rust toolchains and automate development tasks with Python and Bash on Linux.

**CI/CD & build infrastructure**
  Build and maintain delivery pipelines using GitHub Actions, Jenkins and  GitLab CI. 
  Work with Docker based build environments, repository automation, quality checks and release workflows.

**Embedded software & integration**
  Integrate software for automotive and embedded platforms using C, C++ and Python.
  Experience across Linux, FreeRTOS, Zephyr, QNX and AUTOSAR Classic,
  including automotive middleware and platform integration.

**Software quality & supply chain tooling**
  Develop and integrate software bill of materials (SBOM) tooling for complex
  builds, including SPDX outputs, package metadata and dependency relationships.
  I am interested in understanding the EU Cyber Resilience Act (CRA) and its
  practical implications for software supply chains and engineering workflows.
  I also work with automated validation and static-analysis checks.
